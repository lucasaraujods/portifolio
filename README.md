# Portfólio Pessoal

Este é o repositório do meu portfólio pessoal, desenvolvido utilizando apenas **HTML** e **CSS**. O objetivo do projeto é apresentar minhas habilidades, experiências e trabalhos de forma visualmente atrativa e responsiva.

## 🔍 Visão Geral

O portfólio contém as seguintes seções:

- **Sobre mim**
- **Projetos**
- **Habilidades**
- **Contato**

Foi desenvolvido com foco em boas práticas de semântica, acessibilidade e design responsivo.

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
